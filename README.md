# neoipc-app

This repository contains the DHIS2 App Platform application for the NeoIPC Project.

## New to this stack? Start here

If you are new to JavaScript, TypeScript, React, or the DHIS2 App Platform, the
[**`docs/` onboarding guide**](./docs/README.md) is written for you. It walks from
the language up through the framework and then file-by-file through this codebase,
linking to the official documentation throughout.

## Quickstart

```bash
yarn install     # install dependencies (Yarn Classic v1)
yarn start       # run the dev server with hot reload
yarn test        # run the test suite
yarn build       # produce an installable production build (runs the schema-drift check first)
```

See [`docs/01-getting-started.md`](./docs/01-getting-started.md) for details and
[`docs/09-build-test-deploy.md`](./docs/09-build-test-deploy.md) for every command.
